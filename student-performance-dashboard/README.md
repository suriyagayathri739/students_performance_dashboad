# 🎓 Student Performance Dashboard
Black + dark-green Streamlit dashboard (Plotly, Matplotlib, Seaborn, Altair).

## Run in VS Code
```
python -m venv .venv
.venv\Scripts\activate        # Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
Pages: Home (KPIs, student dropdown, HTML export) · Dataset (cleaning, filters, CSV export) · Visualizations · Statistics.
